# CourtFlow — 테니스 복식 대회 운영 매니저

스마트폰과 PC에서 별도 설치 없이 바로 사용할 수 있는 복식 전용 테니스 대회 운영 웹앱입니다.

- **라이브 접속 주소**: https://chuanlgg-source.github.io/tennis-tournament-app/

## 주요 기능
1. **참가자 접수**: 직접 입력 및 엑셀(`.xlsx`/`.xls`)/CSV 업로드, 엑셀 양식 다운로드
2. **실력등급 커스텀**: A~E 5단계(기본), NTRP(2.0~5.0), 금·은·동·신인배 프리셋 및 커스텀 등급 지원
3. **4가지 대회 유형 (복식 전용)**:
   - **토너먼트**: 실력/밸런스 그룹 생성 + BYE(부전승) 자동 배치 및 다음 라운드 자동 진출
   - **개인전 (KDK)**: 인원수 기반 적정 게임수 추천 + 파트너 교체 복식 로테이션
   - **그룹전 (단체전)**: 성별·실력 균등 스네이크 배분 + 그룹대표 오더(게임순서) 입력
   - **이벤트**: 휴식 인원 우선 배정 기반 자유 친선/믹스/타이브레이크 매치
4. **돌발상황 유연 보정**: 홀수 인원·성별 불균형 시 혼성 보정팀 자동 편성, 갑작스런 불참 시 대체 선수 투입 및 기권(W/O) 처리
5. **실시간 승점표 & 멀티 대회 탭**: 승 `+1` / 무 `0` / 패 `-1` (동점 시 각 게임 스코어 총득점 우선), 상단 탭으로 여러 대회 동시 관리
